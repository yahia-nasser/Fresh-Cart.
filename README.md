# 🛒 Fresh Cart — E-commerce Web Application

Fresh Cart is a modern e-commerce web application built to simulate a real-world online shopping experience.
The project focuses on performance, scalability, and clean architecture while demonstrating advanced frontend concepts.

---

## 🚀 Live Demo

🔗 https://fresh-cart-ekbf.vercel.app/

---

## 🧠 Project Overview

Fresh Cart allows users to:

* Browse products
* Filter and search items
* Add/remove items from cart
* Manage cart state dynamically
* Complete checkout flow (UI simulation)

The application demonstrates real-world state management and API integration patterns.

---

## 🛠 Tech Stack

* React 
* TypeScript
* Tailwind CSS
* Context API / State Management
* REST API Integration
* Responsive Design
* DaisyUI

## ✨ Key Features
